## Quick start

1. Extract this archive to an ordinary Windows folder.
2. Double-click `START-DIT-WINDOWS.cmd`.
3. Open `http://localhost:4173`.
4. Watch the three characters; point at one to focus and click to open its memory dossier.
5. Enable `SOUND OFF` in the header if you want the quiet synthesized sci-fi effects.
6. Open **TRANSMISSIONS** to inspect the complete research event history and **NETWORK** to inspect real verified records.
