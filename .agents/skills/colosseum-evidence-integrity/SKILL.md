---
name: colosseum-evidence-integrity
description: Maintain genuine output, deterministic grading, and honest evidence provenance.
---

Trace every displayed outcome to an actual checker event. Re-grade captured outputs against the exact challenge version. Store model/revision, runtime, input, configuration fingerprint, parameters, timestamps, output, checker, error, and provenance. An error or cancellation has no score. Reject unsafe evidence links and invalid imports.

Keep deterministic player practice separate from local model output and recorded replay. Never call replay LIVE. Local completion does not become independently verified public evidence. Player progression tracks learning/configuration and cannot increase model ratings. Comparison requires identical prompts and budgets; report actual outputs even when wrong. Add regression tests for forged verdicts, mismatched identities, and failed execution before publication.
