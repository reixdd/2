Inspect model research and registry metadata, pinned artifact revisions, license sources, worker adapter, and runtime tests. Do not use availability labels as proof. AVAILABLE TO PREPARE means configured artifacts; PLAYABLE — VERIFIED requires initialization plus a genuine generation and deterministic evaluation in that session. Keep memory estimates distinct from measured values; never guess peak memory.

Show total artifact bytes before consent. Fetch only allowlisted HTTPS artifacts after explicit action. Run inference in a worker, stream captured deltas, time initialization/generation, and terminate workers on cancellation. Test slow/failed downloads and unsupported browsers. No paid provider fallback. Keep weights out of static deployment ZIPs. Preserve native CPU source separately; the public website must not depend on the owner's computer. Review Gemma/LFM licenses and actual backend support before promoting candidates. Record exact model identity, limitations, test device, and authentic outputs.
